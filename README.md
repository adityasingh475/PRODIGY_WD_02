# 🌟 About

Chronix is a modern and elegant productivity web application built using **HTML, CSS, and JavaScript**.

It combines a **Stopwatch**, **Countdown Timer**, and **Pomodoro Timer** into one beautiful interface designed for focus and productivity.

---

# ✨ Features

### ⏱ Stopwatch

- Start / Pause
- Reset
- Lap Recording
- Undo Last Lap

### ⏳ Countdown Timer

- Hours
- Minutes
- Seconds
- Quick Presets
- Circular Progress Ring

### 🍅 Pomodoro

- Focus Session
- Short Break
- Long Break
- Clean Productivity Layout

### 📊 Analytics

- Lap Analytics
- Session Statistics
- Interactive Charts

### 📁 Session History

- Local Storage
- Previous Sessions
- Delete History

### 📤 Export

- CSV Export
- JSON Export
- Copy Summary

### 🎨 UI

- Glassmorphism
- Aurora Background
- Cursor Glow
- Ripple Effects
- Dark / Light Theme
- Accent Colors
- Responsive Design
